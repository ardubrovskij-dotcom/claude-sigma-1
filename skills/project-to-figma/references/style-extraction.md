# Извлечение стиля из контекста

## Содержание
- Брендбук и гайдлайны (PDF, docx, текст)
- Код: CSS, Tailwind, токены
- Изображения: логотипы, скриншоты, референсы
- Существующий макет Figma
- Стиль с нуля
- Контраст
- Подбор шрифтов

## Брендбук и гайдлайны

Ищи разделы «Цвета / Colors / Palette», «Типографика / Typography», «Логотип», «Tone of voice», «Do / Don't».

- Цвета: бери hex. Если даны только RGB/CMYK/Pantone — переведи RGB в hex; CMYK/Pantone переводи приблизительно и помечай «≈».
- Роли: «основной / primary» → `primary`; «дополнительные» → `accent`/`surface`; фон обычно не указан — выводи из примеров (светлый/тёмный).
- Шрифты: семейство + начертания. Если указан платный шрифт (Graphik, Circular, SF Pro), он может отсутствовать в Figma — проверь `list_fonts`.
- Запреты (не растягивать логотип, не использовать цвет X на Y) — соблюдай и упомяни в брифе.

## Код: CSS, Tailwind, токены

| Где | Что брать |
|---|---|
| `tailwind.config.*` → `theme.extend.colors`, `fontFamily`, `borderRadius` | Палитра, шрифты, радиусы |
| CSS-переменные `:root { --primary: … }` | Роли по именам переменных |
| `tokens.json`, `theme.ts`, `design-tokens/*` | Готовая система — переносить как есть |
| `font-family` в глобальных стилях, `<link>` Google Fonts | Шрифты |
| Повторяющиеся `padding/gap` | Шаг сетки (обычно 4 или 8) |

Имена ролей в коде (`--brand-500`, `colors.ink`) сопоставь с ролями брифа и покажи соответствие.

## Изображения

Логотип, скриншоты сайта/приложения, референсы, которые прислал пользователь.

- Оцени 3–5 доминирующих цветов: фон, основной текст, акцент (кнопки, ссылки), дополнительные. Hex с картинки — приблизительный (`≈`); если цвет бренда критичен, спроси точный в брифе.
- Определи характер шрифта (гротеск / антиква / геометрический / моно) и подбери доступный аналог — назвать точный шрифт по картинке обычно нельзя, так и скажи.
- Отметь радиусы (острые / мягкие / пилюли), плотность, наличие теней, фотографий, иллюстраций.
- Логотип в SVG (текстом в проекте) → можно вставить через `create_svg`. Растровый логотип вставить нельзя → текстовый логотип названием продукта или заглушка.

## Существующий макет Figma

1. `get_page {depth: 1}` — какие фреймы есть.
2. `figma_screenshot` по 1–2 типичным фреймам — общий характер.
3. `get_node {id, depth: 2}` — точные `fills` (hex), `fontName`, `fontSize` у заголовков и текста.
4. `find_nodes {type: "TEXT", rootId}` — набор размеров шрифта → шкала.

Новые фреймы делай в той же системе: те же отступы от краёв, те же размеры заголовков, тот же мотив. Предложения «улучшить стиль» — только словами в брифе, не самовольно.

## Стиль с нуля

Когда стиля нет нигде, выводи его из предмета и аудитории, а не из привычки:

| Характер проекта | Направление |
|---|---|
| Финансы, B2B, право | Сдержанная палитра, один насыщенный акцент, строгий гротеск, малые радиусы |
| Потребительское приложение, lifestyle | Тёплые/яркие акценты, мягкие радиусы, дружелюбный геометрический шрифт |
| Технологии, dev-инструменты | Тёмная тема, неон/электрик акцент, моно для деталей |
| Премиум, мода, архитектура | Много воздуха, контрастная антиква в заголовках, монохром + один цвет |
| Образование, дети | Светлый фон, несколько ярких цветов-ролей, крупный шрифт |

Это отправная точка, а не шаблон: подстрой под конкретный проект и помечай всё как `[предложено]`.

## Контраст

Относительная яркость цвета (sRGB, каналы 0–1): для каждого канала `c ≤ 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`, затем `L = 0.2126·R + 0.7152·G + 0.0722·B`. Контраст = `(L_светлее + 0.05) / (L_темнее + 0.05)`.

| Где | Минимум |
|---|---|
| Основной текст | 4.5 : 1 |
| Крупные заголовки (≥ 24 px Bold или ≥ 32 px) | 3 : 1 |
| Иконки, границы полей | 3 : 1 |

Ориентиры: белый на `#3B82F6` ≈ 3.7 (только крупный текст), белый на `#1D4ED8` ≈ 6.7, `#64748B` на белом ≈ 4.8, `#94A3B8` на белом ≈ 2.6 (не для текста).

## Подбор шрифтов

1. `list_fonts {family: "<бренд>"}` — есть ли шрифт и как называются начертания.
2. Нет — ближайший доступный по характеру; проверь его тоже через `list_fonts`.
3. Совсем ничего не нашлось — `Inter` (есть почти всегда) и сообщи об этом.

Частые замены: Graphik/Circular → Inter, Manrope, DM Sans; Helvetica/Arial → Inter; Georgia/Tiempos → Playfair Display, Lora; SF Pro → Inter; Futura → Jost; моно → JetBrains Mono, Roboto Mono.
